📲 Install Aplikasi di HP (Android & iPhone)

🤖 Pengguna Android (Chrome)

  1. Buka link aplikasi ini menggunakan browser Google Chrome.
  2. Ketuk tombol Install Sekarang di bawah (atau ketuk titik tiga ⋮ di kanan atas).
  3. Pilih Install aplikasi / Tambahkan ke Layar Utama.

🍎 Pengguna iPhone / iPad (Safari)

  1. Pastikan link aplikasi ini dibuka menggunakan browser Safari.
  2. Ketuk ikon Bagikan (Share) berbentuk kotak dengan panah ke atas di bagian bawah layar.
  3. Geser ke bawah lalu ketuk Tambah ke Layar Utama (Add to Home Screen).
  4. Ketuk Tambah (Add) di pojok kanan atas. Ikon Bakery Studio akan langsung muncul di layar utama iPhone.
